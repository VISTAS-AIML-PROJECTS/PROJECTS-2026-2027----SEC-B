🛠️ Setup Instructions ▼

To use Stratosphere with Zerodha, you need a Kite Connect app.

  • Go to kite.trade/connect and log in.
  • Click Create App (costs ₹2000/month).
  • Set the Redirect URL to something like http://127.0.0.1:8000.
  • Once created, you will get an API Key and API Secret.
  • Open the .env file in the project root and add:
    KITE_API_KEY=your_api_key_here
    KITE_API_SECRET=your_api_secret_here
  • Restart the Stratosphere server.
  • Note: Access tokens expire daily at 06:00 AM IST. You must perform this login flow once every trading day.
